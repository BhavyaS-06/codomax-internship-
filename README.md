# Codomax Module 2: Prompt Engineering & AI Productivity

This beginner-friendly project demonstrates prompt engineering concepts using Python. It uses example prompts and simulated outputs so it can run without an AI API key.

## Topics covered
- Zero-shot and few-shot prompting
- Role, context, instructions, and constraints
- Structured JSON output
- Text summarization and classification prompt templates
- AI-assisted coding and debugging
- Reusable prompt templates
- Prompt testing report

## Requirements
- Python 3.8 or later
- No third-party packages required

## Run the project
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python main.py
```

The program prints examples of prompt templates and a sample JSON record.

## Project files
- `main.py` — runs the demonstrations
- `prompt_examples.py` — zero-shot, few-shot, role, and context examples
- `structured_output.py` — creates and validates a JSON example
- `productivity_toolkit.py` — reusable prompts for email, resume, coding, and research
- `testing_report.md` — simple prompt evaluation report
- `requirements.txt` — no external dependencies required

## Important note
The project demonstrates how prompts are designed. It does not call a live AI model or automatically generate model responses. To use a real model, connect an approved API and keep API keys private.
